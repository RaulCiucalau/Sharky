# Sharky – 2D Browser Game 🦈

**Sharky** is a 2D browser-based game where you control a shark exploring the ocean depths. Collect coins, battle enemies using bubbles and poisoned bubbles, and face an epic **final boss** at the end.  
The project focuses on **object-oriented programming**, game mechanics, and real-time interactions.

---

## 🛠️ Tech Stack

- HTML5  
- CSS  
- JavaScript (Vanilla)  
- Object-Oriented Programming (OOP)  
- Git & GitHub  

---

## 📂 Repository

## 🎮 Gameplay Overview

- Control Sharky using keyboard inputs  
- Collect coins and power-ups  
- Attack enemies with bubbles and poisoned bubbles  
- Manage health and energy  
- Defeat the final boss to complete the game  

---

## ⭐ Features

- Character movement and collision detection  
- Enemy movement and final boss battle  
- Collectable items (coins, bubbles, poisoned bubbles)  
- Health and energy management system  
- Sound effects and animated elements  
- Responsive canvas rendering
